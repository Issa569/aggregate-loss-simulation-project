1. Introduction

In this project, we study the aggregate annual loss of an automobile insurance portfolio using the collective risk model.

The number of claims is modeled using a Poisson distribution, while the claim severity follows a Gamma distribution. The aggregate loss is then obtained by combining both components.

To analyze the distribution of aggregate loss, we use two approaches. The first approach is Monte Carlo simulation, where we generate a large number of scenarios to approximate the distribution. The second approach is Panjer recursion, which provides a recursive method to compute the aggregate loss distribution.

The analysis is carried out under four different scenarios. We first consider the base case without any coverage modification. We then introduce a deductible, a policy limit, and finally a combination of both.

For each case, we compute key risk measures, including the expected loss, variance, 95th percentile, and the probability that the aggregate loss exceeds a given threshold. These results allow us to compare the impact of coverage modifications and evaluate the consistency between the two methods.

2. Model Assumptions and Parameter Setup

We model the aggregate loss using the collective risk framework, where the total loss is driven by both the number of claims and their respective sizes.

The number of claims is assumed to follow a Poisson distribution with mean equal to 2:

N ~ Poisson(2)

The claim severity on the other hand follows a Gamma distribution with mean equal to 4000 and standard deviation equal to 2000.

To simulate from this distribution, we express the Gamma distribution in terms of its shape (α) and scale (θ) parameters.

# Poisson parameter
lambda <- 2

# Severity parameters
mean_X <- 4000
sd_X <- 2000
var_X <- sd_X^2

# Gamma parameters
alpha <- mean_X^2 / var_X
theta <- var_X / mean_X

## [1] 4
theta
## [1] 1000

The Gamma distribution parameters are therefore α = 4 and θ = 1,000.

This specification allows us to simulate claim amounts that match the given mean and variability. It also ensures that the severity distribution captures the presence of larger claims, which is a key feature in insurance data.

3. Monte Carlo Simulation

We begin by analyzing the aggregate loss using Monte Carlo simulation.

In each simulation, the number of claims is first generated from a Poisson distribution. Then, for each claim, a severity value is generated from the Gamma distribution. The aggregate loss is obtained by summing all claim amounts within the simulation.

This process is repeated a large number of times to approximate the distribution of aggregate loss.

To ensure computational efficiency, the simulation was first performed with 10,000 iterations.

The number of simulations was then increased to 100,000 to check the stability of the results. The main measures, including the mean and the tail probabilities, showed only minor differences between the two runs.

This indicates that the estimates had stabilized, and therefore 10,000 simulations were considered sufficient for the analysis.

3.1. Base case simulation

We first consider the base case without any coverage modification.

set.seed(123)

# Number of simulations
n_sim <- 10000

S_ground <- numeric(n_sim)

for (i in 1:n_sim) {
  N <- rpois(1, lambda)
  
  if (N > 0) {
    X <- rgamma(N, shape = alpha, scale = theta)
    S_ground[i] <- sum(X)
  } else {
    S_ground[i] <- 0
  }
}

3.2. Coverage modifications

We then extend the simulation to include the three coverage modifications required in the project.

For the deductible case, each claim payment is reduced by 500, with negative values replaced by zero. For the policy limit case, each claim payment is capped at 10,000. Finally, in the combined case, the deductible is first applied and the resulting payment is then capped by the policy limit.

d <- 500
u <- 10000

S_ded <- numeric(n_sim)
S_lim <- numeric(n_sim)
S_both <- numeric(n_sim)

for (i in 1:n_sim) {
  N <- rpois(1, lambda)
  
  if (N > 0) {
    X <- rgamma(N, shape = alpha, scale = theta)
    
    X_ded  <- pmax(X - d, 0)
    X_lim  <- pmin(X, u)
    X_both <- pmin(pmax(X - d, 0), u)
    
    S_ded[i]  <- sum(X_ded)
    S_lim[i]  <- sum(X_lim)
    S_both[i] <- sum(X_both)
  } else {
    S_ded[i]  <- 0
    S_lim[i]  <- 0
    S_both[i] <- 0
  }
}

3.5. Interpretation of Monte Carlo results

From the Monte Carlo results, we observe clear differences across the four cases.

The base case produces the highest expected aggregate loss, approximately 7,900, with a relatively high variability and a 95th percentile close to 19,800, since the insurer retains the full amount of every claim.

When the deductible is introduced, the expected loss decreases noticeably to around 7,000. This is expected, since part of the smaller claims is absorbed by the policyholder rather than the insurer. As a result, both the variance and the tail probability decrease, with the probability of exceeding 15,000 dropping from about 13.5% to below 10%.

The policy limit has a different impact. While the expected loss remains close to the ground-up case, the effect is more visible in the upper tail of the distribution. By capping large claims, the limit reduces extreme outcomes, although the reduction is less pronounced compared to the deductible.

When both the deductible and the policy limit are applied together, the impact becomes more significant. The expected loss drops further to approximately 6,950, and the tail risk is reduced even more, with the probability of exceeding 15,000 falling to around 9%.

Overall, the combined effect provides the strongest reduction in risk, as it limits both small frequent losses and large extreme losses.

4. Panjer Recursion

In addition to simulation, we analyze the aggregate loss distribution using Panjer recursion.

This method provides a recursive way to compute the probability distribution of aggregate loss when the claim frequency belongs to a specific class of distributions. In our case, the number of claims follows a Poisson distribution, that belongs to the (a, b, 0) class with a = 0 = 0, and b = λ, which allows the use of Panjer recursion.

Unlike Monte Carlo simulation, which relies on random sampling, Panjer recursion computes the distribution directly through a deterministic procedure. This allows us to obtain an exact approximation of the aggregate loss distribution, given a discretized severity model.

4.1. Severity discretization

Since Panjer recursion operates on discrete distributions, the continuous severity distribution must first be discretized.

We approximate the Gamma distribution by dividing the range of possible losses into intervals of fixed width, and assigning probabilities to each interval. This allows us to construct a discrete severity distribution that can be used in the recursion.

h <- 100   # discretization step
max_loss <- 50000

x_vals <- seq(0, max_loss, by = h)

# Discretized severity probabilities
fx <- pgamma(x_vals + h, shape = alpha, scale = theta) -
      pgamma(x_vals, shape = alpha, scale = theta)

# Normalize (for numerical stability)
fx <- fx / sum(fx)

4.2. Panjer Recursion implementation

Using the discretized severity distribution, we apply the Panjer recursion formula to compute the aggregate loss distribution.

The recursion starts from the probability of zero loss and builds the distribution step by step using the properties of the Poisson frequency distribution.

g <- numeric(length(x_vals))
g[1] <- exp(-lambda)   # g(0)

for (k in 2:length(x_vals)) {
  g[k] <- (lambda / (k - 1)) * sum(
    (1:(k - 1)) * fx[2:k] * g[(k - 1):1]
  )
}

4.3. Summary measures

Once the aggregate loss distribution is obtained, we compute the same summary measures used in the Monte Carlo analysis.

# Convert to actual loss values
loss_vals <- x_vals

panjer_mean <- sum(loss_vals * g)
panjer_var  <- sum((loss_vals^2) * g) - panjer_mean^2

cdf_vals <- cumsum(g)

panjer_q95 <- loss_vals[min(which(cdf_vals >= 0.95))]
panjer_prob <- sum(g[loss_vals > 15000])

panjer_results <- c(
  Mean = panjer_mean,
  Variance = panjer_var,
  `95th Percentile` = panjer_q95,
  `P(S > 15000)` = panjer_prob
)

4.4 Coverage modifications

We now extend the Panjer recursion to the three coverage modifications considered earlier.

Since the recursion depends on the severity distribution, the main adjustment is made at the severity level.

We begin by discretizing the modified severities under each coverage condition.

For the deductible case, the insurer payment is given by (X - d)+ , which creates a mass at zero because some losses fall below the deductible.

For the policy limit case, the insurer payment is capped at the policy limit u, which shifts part of the upper tail to the limit point.

For the combined case, the payment is first reduced by the deductible and then capped by the policy limit.

d <- 500
u <- 10000

panjer_poisson <- function(fx, lambda) {
  g <- numeric(length(fx))
  g[1] <- exp(-lambda)   # Probability of zero aggregate loss
  
  for (k in 2:length(fx)) {
    g[k] <- (lambda / (k - 1)) * sum(
      (1:(k - 1)) * fx[2:k] * g[(k - 1):1]
    )
  }
  
  return(g)
}

# Deductible case: Y = (X - d)+
fx_ded <- numeric(length(x_vals))
fx_ded[1] <- pgamma(d, shape = alpha, scale = theta)

for (k in 2:length(x_vals)) {
  lower <- d + x_vals[k]
  upper <- d + x_vals[k] + h
  fx_ded[k] <- pgamma(upper, shape = alpha, scale = theta) -
               pgamma(lower, shape = alpha, scale = theta)
}
fx_ded <- fx_ded / sum(fx_ded)

# Limit case: Y = min(X, u)
fx_lim <- numeric(length(x_vals))

for (k in 1:(length(x_vals) - 1)) {
  if (x_vals[k] < u) {
    fx_lim[k] <- pgamma(x_vals[k] + h, shape = alpha, scale = theta) -
                 pgamma(x_vals[k], shape = alpha, scale = theta)
  }
}

limit_index <- which.min(abs(x_vals - u))
fx_lim[limit_index] <- fx_lim[limit_index] +
                       (1 - pgamma(u, shape = alpha, scale = theta))
fx_lim <- fx_lim / sum(fx_lim)

# Both deductible and limit: Y = min((X - d)+, u)
fx_both <- numeric(length(x_vals))
fx_both[1] <- pgamma(d, shape = alpha, scale = theta)

for (k in 2:(length(x_vals) - 1)) {
  if (x_vals[k] < u) {
    lower <- d + x_vals[k]
    upper <- d + x_vals[k] + h
    fx_both[k] <- pgamma(upper, shape = alpha, scale = theta) -
                  pgamma(lower, shape = alpha, scale = theta)
  }
}

both_limit_index <- which.min(abs(x_vals - u))
fx_both[both_limit_index] <- fx_both[both_limit_index] +
                             (1 - pgamma(d + u, shape = alpha, scale = theta))
fx_both <- fx_both / sum(fx_both)

c(sum(fx_ded), sum(fx_lim), sum(fx_both))

4.5. Summary measures for all cases

compute_panjer_stats <- function(g, loss_vals) {
  mean_val <- sum(loss_vals * g)
  var_val  <- sum((loss_vals^2) * g) - mean_val^2
  cdf_vals <- cumsum(g)
  
  idx <- which(cdf_vals >= 0.95)
  q95_val <- if (length(idx) > 0) loss_vals[min(idx)] else NA
  
  prob_val <- sum(g[loss_vals > 15000])
  
  c(
    Mean = mean_val,
    Variance = var_val,
    `95th Percentile` = q95_val,
    `P(S > 15000)` = prob_val
  )
}

6. Conclusion

In this project, the aggregate loss distribution was analyzed using both Monte Carlo simulation and Panjer recursion under different coverage scenarios.

The results obtained from the two methods were highly consistent across all cases. This confirms that both approaches provide reliable estimates of the aggregate loss distribution, despite the differences in their implementation.

The analysis also highlights the impact of coverage modifications on insurer risk. The deductible reduces the effect of smaller claims, leading to a noticeable decrease in the expected loss and variability. The policy limit mainly affects larger claims, reducing the upper tail of the distribution. When both are applied together, the reduction becomes more significant, providing the strongest protection against both frequent and extreme losses.

From a practical perspective, Monte Carlo simulation is easier to implement and more flexible, while Panjer recursion offers a more structured and deterministic approach. The agreement between the two methods strengthens the confidence in the results obtained.
