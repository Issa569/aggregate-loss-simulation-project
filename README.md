# Aggregate Loss Modeling

## Project Overview

In this project, we model aggregate insurance losses using Monte Carlo simulation and Panjer recursion, while analyzing the impact of deductibles and policy limits on risk distribution.

The project was developed in R as part of an actuarial modeling course, with a focus on understanding the practical behavior of aggregate loss distributions under different insurance conditions.

## Objectives

- Model aggregate insurance losses using frequency-severity methods
- Apply Monte Carlo simulation techniques
- Implement Panjer recursion for recursive aggregate loss calculations
- Analyze the effect of deductibles and policy limits
- Compare simulation and recursive approaches

## Methods Used

- Monte Carlo Simulation
- Panjer Recursion
- Frequency-Severity Modeling
- Aggregate Loss Distributions
- Deductible and Coverage Limit Analysis

## Tools & Technologies

- R
- R Markdown
